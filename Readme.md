# Personal AI Agent

## Overview

This Personal AI Agent helps users organize information, answer questions, summarize uploaded files, and provide guidance for internship assignments. It demonstrates the use of AI to improve productivity and decision-making.


## Target Users

- Students
- Internship participants
- Researchers
- Software developers



## Features

- Answer user questions
- Summarize documents
- Explain machine learning concepts
- Generate reports
- Portfolio assistance
- Research paper assistance



## Technologies Used

- Claude AI
- HTML
- CSS
- GitHub Pages



## Setup Instructions

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Use the portfolio and AI agent as documented.



## Usage Example

Example:

User:
> Summarize my resume.

Agent:
> Reads the uploaded resume and summarizes education, skills, and projects.



## Architecture

```
User
   │
   ▼
Portfolio Website
   │
Claude AI
   │
Generated Response
```
