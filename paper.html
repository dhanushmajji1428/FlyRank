Content Refresh Prediction Using Machine Learning

FlyRank Machine Learning Internship – Capstone Research Paper

Author: Dhanush Kumar

Abstract

This study investigates whether machine learning can support content refresh decisions. A Decision Tree model was trained and compared with a baseline using the FlyRank ML Internship dataset. The workflow included preprocessing, validation, and leakage checks. The Decision Tree outperformed the baseline while remaining interpretable. The results demonstrate the value of machine learning as a decision-support tool with appropriate limitations.

Introduction

Keeping web content up to date is important for maintaining user engagement and search performance. This project evaluates whether a Decision Tree classifier can improve content refresh prediction compared with a baseline approach.

Data

The project uses the FlyRank Machine Learning Internship dataset. This report intentionally excludes client names, URLs, search queries, and other non-public information. Data was cleaned and split into 80% training and 20% testing subsets.

Methodology

  • Data preprocessing
  • Feature selection
  • Baseline evaluation
  • Decision Tree training
  • 80/20 train-test split
  • Validation and feature leakage checks

Results

ModelAccuracy
Baseline98.18%
Decision Tree99.98%

The Decision Tree achieved higher predictive performance than the baseline while remaining easy to interpret.

Limitations

  • Single internship dataset.
  • Results should be interpreted as decision support.
  • Future work can evaluate additional models and larger datasets.

Ranked Recommendations

  1. Prioritize content with the highest predicted refresh score.
  2. Review recommendations with human oversight.
  3. Monitor model performance after deployment.
  4. Retrain periodically with new data.
  5. Expand the feature set for future work.
